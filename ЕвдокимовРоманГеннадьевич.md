Cadastre_App - информационная система для ведения учета объектов недвижимости, созданное для ООО "3Д КАДАСТР".

Функционал:
1. Просмотр списка актуальных объектов недвижимости
2. Добавление, редактирование и удаление объектов

Инструменты разработки:
1. Язык программирования C#
2. Платформа .NET Framework
3. Среда разработки Visual Studio 2022
